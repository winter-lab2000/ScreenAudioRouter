# Screen Audio Router — Release Notes template

## v0.1.0

### 功能
- 按显示器绑定默认扬声器 / 麦克风
- 窗口或播放进程在屏幕间移动时自动切换默认设备
- 显示器识别真实硬件名，并按名称自动匹配 HDMI 音频
- macOS 风格主界面：路由映射 / 独立设置页
- 系统托盘：菜单可点外部关闭、开机自启开关
- 开机自启（HKCU Run，软件内可开关）

### 系统要求
- Windows 10 / 11 x64
- 多显示器 + 至少两个不同音频输出端点

### 已知限制
- 麦克风切换的是系统默认通信设备，应用内锁定设备时无效
- 多应用不能同时分别绑定不同设备并行出声（默认设备模型）
- 两块屏绑同一输出设备时，拖动窗口听感无变化（预期行为）
